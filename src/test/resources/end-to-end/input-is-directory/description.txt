BUG: when the input file is a directory, the program terminates with an uncaught
UncheckedIOException and a stack trace, and the exit status is 1.  The read failure happens while
iterating over lines, and the iterator wraps it in an unchecked exception, which the program's
"catch (IOException)" does not catch.  The program should instead print the same kind of message
that it prints for an unreadable file, and exit with status 2.
