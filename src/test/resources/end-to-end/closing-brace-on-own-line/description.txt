BUG: a line that consists of only whitespace and a closing brace -- such as the last line of a
multi-line field value, which is very common formatting -- is treated as the end of the entry.  The
rest of the entry is then outside any entry, so it is silently deleted.  The output is not even
valid BibTeX: the entry that it contains is not closed.  There is no diagnostic, and the exit
status is 0.
